【使用方法】

**一.配置游戏**

1.解压本软件

2.下载其他支持本软件的MOD安装依赖并放进本软件的games文件夹

3.打开软件，登录（无法登录请先注册，登录与注册无法在中国大陆网络环境完成）

4.点击“游戏”，选择想管理MOD的游戏

5.点击设置页面，根据相关内容指引填写设置或执行配置操作

**二.安装MOD**

1.打开“MOD列表”页面，将MOD压缩包拖入窗口

2.软件会自动识别并将MOD安装到相关软件的文件夹，若未识别成功则需手动选择。

3.在管理界面开关MOD即可实现MOD的管理

4.点击“启动游戏”，则会通过对应游戏的外部MOD注入器实现启动。

**三.卸载MOD**

在管理界面右键MOD即可打开菜单，在菜单中可删除已安装的MOD
